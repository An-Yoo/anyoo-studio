# AnYoo studio

1인 AI 제작 스튜디오 AnYoo의 포트폴리오 정적 사이트.

- 빌드 도구 없음. `index.html`을 브라우저로 열면 된다.
- 저장소 이름: `anyoo-studio` → 공개 주소 `https://an-yoo.github.io/anyoo-studio/`
- GitHub Pages: 저장소 Settings → Pages → `main` 브랜치 `/ (root)`.
- 구조: `index.html`(소개·프로젝트·작업 방식·질문), `projects/*.html`(케이스 파일), `assets/`(스타일·테마 전환).
- 공개 글에는 토큰·키·계정·이메일·로컬 경로를 넣지 않는다.
